# Quick Install

One command:

```bash
curl -fsSL https://raw.githubusercontent.com/rickeyward17653-max/momnz/main/install.sh -o /tmp/install.sh && chmod +x /tmp/install.sh && sudo REPO_URL="https://github.com/rickeyward17653-max/momnz.git" INSTALL_CYBERPANEL=1 bash /tmp/install.sh
```

For domain SSL:

```bash
sudo DOMAIN="panel.example.com" REPO_URL="https://github.com/rickeyward17653-max/momnz.git" bash /tmp/install.sh
```
